## Задание 2

Для выполнения данного задания вам понадобится файл `faculty_4.csv`. В файле возможно наличие случайных пробелов в начале или конце слов, добавленных оператором по ошибке. Для данного файла гарантируется, что все фамилии преподавателей записаны в качестве одного слова.

Напишите bash-скрипт с именем `script.sh`, последовательно решающий следующие задачи:

### 0) Создание пустой директории с именем data_analysis.

Убедитесь, что ваш скрипт корректно отрабатывает в случае, когда директория с данным именем уже существует.

**Решение:** [`sol2.sh`](sol2.sh)

---

### 1) Создание файла research_themes внутри директории data_analysis, который содержит все уникальные темы исследований в алфавитном порядке, а последняя строка в данном файле это число всех уникальных направлений исследования.

**Решение:** [`sol2.sh`](sol2.sh)

**Результат:** `data_analysis/research_themes.txt`

---

### 2) Создание файла very_big_groups.txt внутри директории data_analysis, который будет содержать названия всех направлений исследования, в которых принимают участие более 12 человек.

**Решение:** [`sol2.sh`](sol2.sh)

**Результат:** `data_analysis/very_big_groups.txt`

---

### 3) Создание файла joined.csv внутри директории data_analysis, который содержит информацию о всех исследователях, занимающихся одновременно направлениями “Artificial Intelligence” и “Machine Learning”.

**Решение:** [`sol2.sh`](sol2.sh)

**Результат:** `data_analysis/joined.csv`

---

### 4) Создание файла sorted_names.txt внутри директории data_analysis, который содержит полные имена всех исследователей в алфавитном порядке их фамилий.

**Решение:** [`sol2.sh`](sol2.sh)

**Результат:** `data_analysis/sorted_names.txt`
